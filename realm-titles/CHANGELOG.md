# Changelog

## 0.1.0 — Beta

- Added the Royal Seal Desk: an original two-block medieval model with dark wood, gold trim, green heraldic banner, illuminated register, quill and wax seal; crafting recipe, creative tab and four orientations.
- Added a public honours registry with search, paging and a parchment-and-gold interface in English, European Portuguese and Brazilian Portuguese.
- The current sworn Realm Council governor can create, edit and assign custom titles, then revoke individual appointments. Standalone servers can appoint an explicit steward.
- Supports multiple titles per character, permanent honours and temporary appointments lasting 1–365 real days. Honours persist between governments.
- Added a persistent server registry, bounded requests, physical desk sessions and fresh authority checks on every change.
- Integrated optional Chronicles RP public character names and eligibility, Realm Identity 0.1.1 live public titles, and Realm Notifications assignment, revocation and expiry notices.
- Added the version 1 read-only public Titles API. Titles do not change money, player statistics, chat prefixes or RP names.
