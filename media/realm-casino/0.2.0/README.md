# Realm Casino

Actual Minecraft 1.21.1 NeoForge integrated-client captures of six physical casino blocks, authoritative games and owner/rules menus. Characters and funds are test fixtures; no real money is involved. Server suites verify monetary conservation, liabilities, journals and replay rejection. These captures do not establish an authenticated two-client session.
