# Realm Progression — imagens

[Galeria completa](0.1.0/README.md) · [Download dos PNGs](0.1.0/realm-progression-0.1.0-media.zip) · [Guia](../../realm-progression/README.md)

Capturas reais de Minecraft 1.21.1 com Create 6.0.10 e Realm Treasury 0.4.0. O cenário prepara a construção, as personagens, os fundos e os materiais iniciais. Os menus, a doação, a validação das permissões e os crafts utilizam o código de produção. Dois clientes com identidades de teste offline ligam-se por TCP LAN.

![Mesa de Investigação original](0.1.0/research-table-closeup.png)

**Suggested title:** The Research Table. **Caption:** A carved medieval table with brass fittings, a blue cloth, an open atlas, a jade bookmark, an astrolabe, a charter and a quill. All tables consult the same kingdom-wide research.

![Meta do Create](0.1.0/research-create-locked.png)

**Suggested title:** A kingdom grows together. **Caption:** Reach the public treasury goal to permanently unlock supported crafting for every player. The money stays in the treasury.

![Seleção de outro mod](0.1.0/research-installed-mods.png)

**Suggested title:** Choose your own progression. **Caption:** Administrators can search server-installed mods and set independent crafting goals through a physical menu.
