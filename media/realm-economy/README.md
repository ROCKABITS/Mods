# Realm Economy — imagens

[Download dos 48 PNGs](0.5.0/realm-economy-0.5.0-media.zip) · [Galeria completa](0.5.0/README.md) · [Guia](../../realm-economy/README.md)

Capturas reais de Minecraft 1.21.1/NeoForge. A construção, as personagens, os fundos e os materiais são demonstrações. Os menus e as operações financeiras são os de produção, com carteira Realm Origins e Realm Treasury reais. O período de beacon do cenário foi configurado em 10 segundos para verificar a expiração; o padrão é 600 segundos.

## Cofre e economia das colónias

[Funcionamento e configuração](../../realm-economy/MINECOLONIES.md). Capturas da integração real com MineColonies 1.1.1403, os seis addons indicados pelo utilizador e dois clientes ligados por TCP LAN, incluindo fecho e reabertura do mundo. As identidades, os fundos, os materiais e a colónia são preparados para o cenário de demonstração.
