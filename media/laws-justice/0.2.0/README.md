# Laws & Justice

Actual Minecraft 1.21.1 NeoForge integrated-client captures of prison blocks, the surveying rod, the justice desk, physical prison administration, elected court interfaces and server-validated warrants. Demonstration buildings, players and sentences are test fixtures; this mod does not generate prisons. Server suites verify custody rules, persistence, permissions and online-only sentence completion. These captures do not establish an authenticated two-client session.
