# laws-justice

Actual Minecraft 1.21.1 NeoForge integrated-client captures of original prison, court, work and register furniture, physical menus, warrants, all six Survival work tasks, fines and bail. Buildings, characters, sentences and the initial wallet funding are authored QA fixtures; the mod never generates prisons or grants that fixture money. Payments use real Chronicles wallets, real Crown income receipts and actual LAN-host shutdown/reopen. No synthetic financial snapshots. Work demonstrations use one unit/one minute per task. This does not establish an authenticated two-client session.
