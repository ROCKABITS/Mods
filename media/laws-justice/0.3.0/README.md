# Laws & Justice

Actual Minecraft 1.21.1 NeoForge integrated-client captures of prison and work furniture, the surveying rod, the justice desk, physical administration, elected court interfaces, sealed warrants and all six community-service tasks. Work demonstrations use one unit and one minute per configured task; default quantities and rewards are larger. Demonstration buildings, players and sentences are test fixtures; this mod does not generate prisons. Server suites verify custody rules, persistence, permissions and online-only sentence completion. These captures do not establish an authenticated two-client session.
