# Chronicles RP 0.5.2 — character creation first

- The Chronicles RP character creator now opens first on a new character's initial join.
- The lineage button opens the native Origins race selector. The optional Origins: Classes choice follows the race, then returns to the same RP form.
- Name, age and the unfinished RP form are kept while visiting Origins.
- The first creation step and final confirmation require the server-confirmed Origins selections.
- Existing RP characters keep their normal Origins flow, including new pending layers and Orb of Origin selections.
- English and Portuguese instructions explain the new button flow.
- Retains the 0.5.1 Elytrian claustrophobia fix, existing character data, signatures and economy.

Minecraft Java 1.21.1 · NeoForge 21.1.256 · Java 21.

Origins (NeoForge) 0.3.2 and Jupiter 2.3.7 are required. Origins: Classes (NeoForge) 0.3 is optional. Replace the previous Chronicles RP JAR with `cronicasrp-0.5.2.jar` on the server and clients. Network protocol remains 6.
