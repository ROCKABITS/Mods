# Changelog

## 0.1.0 — Initial beta

- Added player marriage proposals with an engagement ring, explicit consent, expiry and persistent spam protection.
- Added an original two-block medieval wedding altar, 3D rings, sealed certificates, recipes and a creative tab.
- Couples choose their own celebrant and up to two consenting witnesses, with temporary ceremony permissions.
- Added interactive opening, introduction, server-timed objections, individual vows, witness signatures and a final seal.
- Guests can object with the rebindable G key during the default ten-second window. Objections pause the ceremony; both partners must consent before it resumes.
- Added custom parchment overlays, animated rings, gold and rose particles, four original bell sounds and local visual/audio preferences.
- Added separate finances, consolidated joint funds and an optional shared account using the Chronicles RP wallet.
- Added explicit, persistent payment escrow API for opt-in integrations; existing mods retain their normal wallet behavior.
- Added unilateral divorce, agreed divisions with consistent cent rounding, offline credits and remarriage.
- Added optional governed wedding fees paid once to Crown Ledger 0.2.7, live Realm Identity 0.1.2 civil status and server-verified certificate inspection.
- Added optional RP names, notifications and an authoritative administration-provider API.
- Added durable transaction intents, player and LAN-owner save receipts, recovery, audit history, server-side distance/permission checks and document verification.
- Added English, European Portuguese and Brazilian Portuguese translations, domain tests, native GameTests and a four-client TCP LAN validation fixture.
